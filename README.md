## Write from the browser

1. Open https://app.pagescms.org/ and sign in with GitHub.
2. Grant Pages CMS access only to this repository.
3. Select the main branch. The root .pages.yml configures article and image editing.
4. Create an article, fill in title, date and body, and upload images as needed.
5. Enable Publish on website / 发布到网站, then save. GitHub Pages rebuilds automatically.

Articles belong in _posts/ with filenames YYYY-MM-DD-title.md. Future-dated posts are not rendered by default. The starter includes no fabricated articles.

Public repository warning: unpublished articles are hidden from the website but their source and commit history remain public. Never commit confidential drafts or credentials.
